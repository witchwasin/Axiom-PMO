# SRS-004 - Mandatory NFR categories in Strict mode

| | |
|---|---|
| Level | FAIL |
| Gate | Design, Handoff, Release |
| Applies to | Strict (when `Spec depth: full`) |
| Artifacts | `DESIGN/SRS.md` |

## What this rule checks

In Strict mode under full specification depth, `DESIGN/SRS.md` must declare at least one non-functional requirement across core critical operational categories: `performance`, `security`, and `reliability`.

## Why it blocks

High-risk projects touching sensitive customer data, payments, or life safety cannot safely be handed off to engineering without declared constraints on latency, security controls, and reliability expectations.

## How to fix

Add NFR rows in `DESIGN/SRS.md` covering performance, security, and reliability dimensions.
