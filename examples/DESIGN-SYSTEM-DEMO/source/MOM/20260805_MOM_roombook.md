# MOM - RoomBook kickoff

Date: 2026-08-05
Attendees: Demo PM, Demo PO, Demo Tech Lead, Demo Designer

## item-1

Staff waste time walking to meeting rooms that turn out to be occupied. The
office manager keeps a paper sheet at reception that is never current.

Agreed: build a small internal tool that shows room availability for today and
lets staff book a free room themselves.

## item-2

Demo PO asked to see what the tool will look like before any code is written.
The team has been burned before by approving a wireframe and then disagreeing
about the result. Agreed: produce a design system and a one-page visual sheet as
input to the Design Ready decision.

## item-3

Double booking is the failure everyone named. A booking that silently overwrites
another is worse than no tool at all.

## item-4

Out of scope for this slice: recurring bookings, room equipment, catering,
external visitors, and anything that touches the building access system.
