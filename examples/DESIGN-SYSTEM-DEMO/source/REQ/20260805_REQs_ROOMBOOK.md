# REQ - RoomBook

Version: v1
Date: 2026-08-05

| Row | Requirement |
|---|---|
| row 1 | Staff can see which meeting rooms are free right now, without asking anyone. |
| row 2 | Staff can book a free room for a time slot on the current day. |
| row 3 | A room cannot be booked for a time that overlaps an existing booking. |
| row 4 | A member of staff can cancel a booking they made themselves. |
