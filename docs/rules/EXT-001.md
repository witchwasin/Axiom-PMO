# EXT-001 — Externalization registry integrity

`EXTERNALIZATION.json` is a registry, never a copy of outgoing content. Every
transfer entry must record a stable `EXT-###` id, purpose, provider and
provider type, exact outgoing artifact paths with SHA-256 digests, declared
classification, minimization/redaction statement, deterministic scan result,
whether network transfer occurred, status, and timestamp. References must stay
inside the project root.

The validator checks the declared contract. It is not an enterprise DLP system:
it cannot detect semantic trade secrets, enforce provider-account policy, or
verify retention.
